# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitsupdates gibt es für den jeweils aktuellen Stand von `main` bzw. das neueste Release.

## Eine Sicherheitslücke melden

Bitte **keine öffentlichen Issues** für Sicherheitslücken eröffnen.

Melde Schwachstellen vertraulich über
[GitHub Private Vulnerability Reporting](../../security/advisories/new)
(*Security → Report a vulnerability*).

Bitte angeben:

- betroffene Komponente und Version/Commit
- Schritte zur Reproduktion bzw. Proof of Concept
- mögliche Auswirkungen

Wir bestätigen den Eingang innerhalb von 72 Stunden und halten dich über den Stand der Behebung auf dem Laufenden.
