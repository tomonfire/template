# Architecture Decision Records

Wichtige, schwer umkehrbare Entscheidungen werden hier als ADR festgehalten
(Format nach [Michael Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions)).

- Dateiname: `NNNN-kurzer-titel.md` (fortlaufend nummeriert)
- Vorlage: [`0000-template.md`](0000-template.md)
- ADRs werden nicht gelöscht; überholte Entscheidungen werden als *Superseded* markiert.
