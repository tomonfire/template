# Anforderungen

Hier legt der Agent `anforderungen` (Business Owner) für jedes Feature eine kurze Spezifikation ab:
Ziel, User Stories, prüfbare Akzeptanzkriterien, was **nicht** gebaut wird, und die Aufteilung auf das Team.

Dateiname: `NNNN-kurztitel.md` (fortlaufend). Entwickler und Review arbeiten ausschließlich gegen diese Kriterien.
Das spart Zeit und KI-Tokens, weil nichts Unnötiges entsteht.
